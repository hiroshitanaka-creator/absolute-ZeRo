## 2. ブラウザUI

環境：Headless Chromium 144.0.7559.96 / Playwright。

この環境ではブラウザの外部URL遷移を使わず、**生成した単体HTMLを直接読み込ませて検証した**。Storageはテスト用のメモリ実装へ差し替え、実際のアプリのシリアライズ・バリデーション・復帰コードを通した。したがって保存内容の往復検証ではあるが、ブラウザを終了した後のネイティブ保存領域の耐久性テストではない。

UI-01〜UI-16で、初期表示、選択、合成プレビュー、勝利と星、Undo/Redo、キーボード、動けない駒、実際のtouchイベントによるスワイプ、証明経路ヒント、証明経路外からの本物のBlob Worker探索、詰み確認と安全な巻き戻し、モード切替、共有コード、確認ダイアログ、明暗テーマ、全60面のクリック再生を確認。

937手の全盤面走査は、ゲームのボタンとイベントを経由した描画統合テスト。人間が937手を独力で解いたプレイ評価ではない。

## 3. PWA関連のローカルテスト

Service Workerのイベント処理をVMで実行し、インストールするキャッシュのURL、同スコープ旧版のみの削除、明示更新までskipWaitingしないこと、オフライン時のキャッシュ済みindex応答、外部オリジンを横取りしないことを確認。

これはService Workerのネイティブな登録・インストール・HTTPキャッシュ挙動のE2Eテストではない。

## 5. 公開後の受け入れ確認

1. 実際の公開URLでindex・CSS・JS・manifest・アイコンが200で返る。
2. iPhoneのSafariで最初の4面をタップ/スワイプ双方でクリアし、7×7でも押し間違いが許容できるか確認する。
3. 途中で閉じ、再起動して盤面とUndo履歴が戻る。プライベートモードや保存不可時の表示も確認する。
4. ホーム画面追加後にオンラインで一度起動し、キャッシュ準備後に通信を切って再起動する。
5. 日付境界、共有URLのサブパス、ダークテーマ、効果音、モーション軽減を確認する。
6. 更新配信時、プレイ中に強制リロードされず、設定から更新後に途中盤面が保持される。

上記が確認できるまでは「実機で完全動作確認済み」や「本番公開済み」と扱わない。
