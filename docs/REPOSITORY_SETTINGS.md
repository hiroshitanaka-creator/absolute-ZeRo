# リポジトリの紹介設定

GitHubのAbout欄に設定する紹介文とリンクです。現在の連携に設定変更機能がないため、管理者による設定が必要です。

## Description

引いて、ほどいて、ゼロになる。数字の距離だけ跳び、差で駒を消す思考パズル。全60面・毎日3問・自由演習。iPhone / PC対応のPWA、MITライセンス。

## 初回公開

1. Settings → Pages → Source で GitHub Actions を選択。
2. Actions → Test and publish Absolute Zero → Run workflow → main で実行。
3. build / deploy の成功を確認してWebsiteを開く。

About欄はリポジトリのトップページ右側の歯車から編集できます。
